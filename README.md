# College Placement Analytics Dashboard (Excel)

## Project Overview

This project is an interactive Excel dashboard designed to analyze college placement data and uncover insights related to student placements, salary packages, internships, recruiter activity, and skill demand.

The goal is to help educational institutions understand placement performance and identify factors influencing student success.

---

## Business Problem

A college wants to answer the following questions:

* Which branches achieve the highest placement rates?
* Does internship experience improve placement outcomes?
* Which skills are associated with better salary packages?
* Which industries hire the most students?
* How does CGPA affect placement probability?
* Who are the top recruiters?

---

## Dataset Information

The dataset contains 500 student records with the following fields:

* Student_ID
* Branch
* CGPA
* Internship
* Skill
* Placement_Status
* Package_LPA
* Company
* Industry

## Key Insights

* Placement rates vary significantly across branches.
* Students with internship experience achieve better placement outcomes.
* Certain technical and analytical skills are associated with higher salary packages.
* Industry hiring patterns differ across branches.
* Higher CGPA generally correlates with stronger placement performance.
